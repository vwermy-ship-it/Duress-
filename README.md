
# Duress-

A small training page to practice entering a **duress PIN** derived from a 4‑digit code.

## How to publish on GitHub Pages

1. Make sure this repository is named **Duress-** (exactly, with the dash).
2. Put `index.html` in the repository **root** (already included here).
3. Go to **Settings → Pages**.
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` and `/ (root)`
   - Click **Save**.
4. Wait ~30–60 seconds, then open:  
   `https://vwermy-ship-it.github.io/Duress-/`

## Local preview
Just open `index.html` in your browser.

## Notes
- The page loads Tailwind from the CDN and Montserrat from Google Fonts.
- Keyboard shortcuts: digits `0–9`, `Backspace/Delete` = backspace, `C` = clear.
- Your original 4‑digit code is **masked** in Practice mode.
